# 🧠 AI Ticket Resolver — Multi-Agent System

An intelligent ticket resolution system built with multiple AI agents that automatically analyze, assign, and resolve customer support tickets.

---

## 🚀 Features

- **Multi-Agent System:** Each agent performs a distinct function (e.g., ticket classification, response generation, and escalation).
- **FastAPI Backend:** Handles API requests, connects to MongoDB, and orchestrates the agents.
- **Streamlit Frontend:** Provides an interactive dashboard to view and resolve tickets.
- **MongoDB Database:** Stores tickets, resolutions, and AI-generated logs.
- **Dockerized Deployment:** Fully containerized for easy deployment on AWS EC2 or any cloud VM.
